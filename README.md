# Ahmed Mohamed Elsayed Elreefy

I study BEng (Hons) Mechatronics Engineering at the University of Hertfordshire and expect to graduate in 2027. My interests include robotics and control, embedded systems, IoT and computer vision.

## Selected engineering work

- **Modelling and control.** I use motor and chassis models to investigate how a differential-drive robot follows speed and heading references. The project includes PI simulation, digital RST design, a Simscape Multibody builder and ESP32 wireless firmware. I have run ramp and square simulations in MATLAB. Physical validation is in progress. [2WD mobile robot](https://github.com/elsa7er77opp/matlab-simulink)
- **Embedded monitoring.** ATLAS connects an ESP32 sensor node to an MQTT ingestion service, a time-series database and a dashboard. Its detector uses thresholds, changes between samples, rolling statistics and staleness checks. [ATLAS](https://github.com/elsa7er77opp/atlas)
- **Computer vision.** My graduation project investigates pothole and speed-bump detection for autonomous micro-mobility. The current work covers dataset provenance, split leakage, detector training and held-out evaluation. Multisensor integration is planned. [GP-36](https://github.com/elsa7er77opp/Gp-36)
- **Engineering software.** FORGE brings projects, design reviews and technical evidence into a shared workspace. Its API and tests make role and project access rules inspectable. [Project FORGE](https://github.com/elsa7er77opp/project-forge)
- **Desktop applications.** My Windows projects include an authorized local code-review workflow and a studio for rendering layered digital collections. [Secure Code Shield](https://github.com/elsa7er77opp/secure-code-shield) · [Web3 Collection Studio](https://github.com/elsa7er77opp/web3-collection-studio)
